# gazelle

TUI for managing OpenVPN configs on Linux.

## Why?

This is a doodoo project. There are probably other tools that do this better. But I need this to fit my arch rice, and I want to learn rust. I also need to [build something](https://drive.google.com/file/d/1qVFESF3ws8r8B8A0nL0cQLjJ_j7ciSRu/view) for my [hci class](https://www.designstudio-hci.live/schedule#h.74bc374625e19d80_80). So here we are. Building a tui to learn rust and for my arch rice. In python. Without a pkgbuild. These will come later. Maybe.
